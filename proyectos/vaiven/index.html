01

El encargo

Una web para un estudio cuyo producto es el movimiento: tenía que demostrarlo en el primer segundo sin convertirse en una demo técnica ni marear a nadie.

02

La idea

La web como instrumento: todo responde. El nombre cambia de anchura y peso con el cursor, el manifiesto se revela palabra a palabra con el scroll y el proyecto se transforma en la cabecera del caso al navegar.

03

Cómo está hecho

Fuentes variables, View Transitions, canvas generativo por proyecto y un único bucle de animación con suavizado. Sin scroll-jacking, pausado fuera de pantalla y con una versión completa para prefers-reduced-motion.

04

Qué demuestra

Motion con criterio: cada animación da feedback, orienta o cuenta algo. Diseño y código trabajando como una sola disciplina.
